# 接入全站排行榜

1. 在 Supabase 新建项目，在 SQL Editor 新建查询。
2. 复制 `supabase-setup.sql` 全部内容并运行。
3. 在 Connect 或 Settings / API Keys 找到 Project URL 和 Publishable key。
4. 填入 `leaderboard-config.js` 中的 url、key。不要填入数据库密码、secret 或 service_role。
5. 用两个浏览器分别设置昵称、玩一局并失败，检查两个浏览器能否看到相同榜单。
6. 确认后提交并推送，GitHub Pages 地址不变。

每次失败、主动重开、切换难度，都会结算已经开始的游戏。初次打开和未开始的空局不记录。关闭或刷新页面时未结算的游戏不保证记录；本地队列在下次打开或联网后重试。记录从接入功能后开始，无法还原过去所有玩家的记录。

每位玩家用当前浏览器生成的随机编号识别，换设备或清除浏览器数据会视为新玩家；昵称不是登录账号。榜单每人每难度取最高分，同分按服务器记录时间先后排序。所有上传的单局记录保存在 milk_game_runs 中，公开接口仅返回榜单。

这是休闲排行榜：分数由网页上报，数据库有字段与权限限制，但不具备服务端复算或严格防作弊能力。不能直接用作有奖竞赛。

后端未配置时会明确显示“尚未接入数据库”，不会把本机记录冒充全站排名。SQL 需要在 Supabase 实际运行后才能验证。
