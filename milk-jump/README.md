# 奶娃跳一跳

一个使用 HTML、CSS 和 JavaScript 编写的小游戏，无需安装依赖。

## 在 VS Code 中运行

1. 用 VS Code 打开 `C:\Users\lenovo\Desktop\git`。
2. 展开 `milk-jump` 文件夹。
3. 在资源管理器中右键 `index.html`，选择“在文件资源管理器中显示”。
4. 双击 `index.html`，用浏览器打开游戏。
5. 修改代码并保存后，刷新浏览器查看效果。

也可以在已安装 Live Server 扩展时，右键 `index.html` → Open with Live Server。

## 玩法

- 在游戏上方点击奶蛋、奶鼠、奶娃、奶狗或奶鸡，可随时切换角色；不会清空分数，五位角色能力相同。浏览器会记住选择。
- 仅按住绿色“按住，跳一跳”按钮蓄力，松开起跳。键盘操作需先聚焦该按钮。
- 点击画布中的角色，角色会原地弹一下并播放对应声音；不会改变分数或平台位置。
- 蓄力越久跳得越远，最长蓄力 1.5 秒。
- 落在下一块饼干得 1 分，正中央得 2 分。
- 失败后点击“重新开始”；最高分保存在当前浏览器中。

## 文件分工

- `index.html`：文字、按钮和画布结构。
- `style.css`：颜色、布局和手机适配。
- `game.js`：绘制奶娃、蓄力、跳跃、判定与计分。
- `assets/characters.png`：根据提供的参考图，通过内置 imagegen 制作的五角色透明素材。素材提示：保留五位黄色角色的外形和 3D 质感，去除背景与箭头，按奶蛋、奶鼠、奶娃、奶狗、奶鸡排列为一行透明精灵图。

## 修改练习

1. 修改 `index.html` 中的标题。
2. 修改 `style.css` 的页面背景色。
3. 修改 `game.js` 中 `maxCharge = 1500`，调整蓄力速度（单位毫秒）。
4. 保存并运行确认，再在 VS Code 源代码管理里检查差异、暂存、填写提交说明、提交，最后推送。

上传 GitHub 后会保存源码；仓库页面本身不会自动运行游戏。下载后打开 HTML 即可玩。

## 角色声音

`assets/audio/` 中的 WAV 来自桌面 NaiJia/角色：奶娃对应奶蛙/声音.wav，奶鼠对应奶鼠/动作.wav，其余对应各自角色的声音.wav。

- 切换角色时停止声音，不触发发声或弹跳。饼干高度范围 280～450，相邻高度差最多 110，宽度 80～190，中心间距 200～400。最大跳跃距离同步增加为 540。

- 点击画布中的奶娃会触发约 13 秒的大笑：张嘴、身体前后摇晃并抖动，声音来自用户提供的参考视频。切换角色、重开或开始跳跃时停止。动画为参考动作的简化表现。

- 奶娃大笑已改为 NaiJia 原素材的 422 帧透明动画（30 帧/秒，约 14 秒），包含仰头、捧腹、抱头和倒地；声音使用原配 baby.wav。7 张 WebP 图集加载完后可点击奶娃播放。

## 难度与蓄力声音

- 简单：饼干宽 170～215，高度固定。
- 困难：宽 130～180，相邻高度差最多 35。
- 地狱：保留原范围，宽 80～190，相邻高度差最多 110。
- 切换难度重新开始，各难度分别保存最高分；原最高分保留在地狱。
- 按住绿色按钮时，音调在 1.5 秒内从 220 Hz 升至 880 Hz，松开、取消、重开或离开页面时停止。

- 落地按角色绘制宽度计算水平方向重叠，至少 80% 在目标饼干范围内即成功，低于 80% 掉落。

- 每局第 10、20、30…块饼干各有一枚金币，起始饼干算第 1 块。跳跃中碰到金币加 5 分，每枚只可领取一次；重开或切换难度重置计数。

- 第六个角色“袋鼠”：参考用户图片通过内置 imagegen 去除背景，提示为保留造型与坐姿、透明背景；素材 assets/kangaroo.png。点击播放用户视频最前 2.5 秒，音频 assets/audio/kangaroo.wav。上线前运行 supabase-kangaroo-upgrade.sql 允许该角色成绩上传。
